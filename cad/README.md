# CAD Models & Manufacturing Files

This directory contains the computer-aided design files for the physical scissor pantograph mechanism:

## Planned Contents
- `*.SLDPRT`, `*.SLDASM`: SolidWorks 3D parametric CAD models of the linkages, stand, and pins.
- `*.STL`: 3D-printable mesh files ready for slicing.
  - `scissor_arm_60mm.stl`: Main $6.0\text{ cm} \times 1.0\text{ cm}$ linkage with 3 hinge holes ($\varnothing 4.0\text{ mm}$).
  - `scissor_arm_30mm.stl`: Terminal half-linkage ($3.0\text{ cm} \times 1.0\text{ cm}$) with 2 hinge holes.
  - `stand_mount.stl`: Upper suspension anchor bracket.

## Geometric Specifications
- **Arm Length:** $6.0\text{ cm}$ center-to-center
- **Arm Width:** $1.0\text{ cm}$
- **Arm Thickness:** $0.4\text{ cm}$
- **Hole Diameter:** $4.0\text{ mm}$ (clearance fit for pivot pins)
- **Edge Fillet Radius:** $0.5\text{ cm}$
