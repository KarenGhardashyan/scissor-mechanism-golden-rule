# Ultimaker Cura Slicing Profiles & G-Code

This directory contains the print settings, slicer profiles, and toolpaths for fabricating the linkages on an FFF/FDM 3D printer:

## Slicing Parameters
- **Slicer:** Ultimaker Cura
- **Material:** Generic PLA (Polylactic Acid)
- **Nozzle Diameter:** $0.4\text{ mm}$
- **Layer Height:** $0.1\text{ mm}$ (Fine Profile for smooth pivot bearing contact)
- **Print Speed:** $60\text{ mm/s}$
- **Travel Speed:** $120\text{ mm/s}$
- **Infill Density:** $40\% - 60\%$ (Cubic / Gyroid)
- **Wall Line Count:** 3 perimeters ($1.2\text{ mm}$ wall thickness)
- **Top / Bottom Thickness:** $0.8\text{ mm}$ (8 layers)
